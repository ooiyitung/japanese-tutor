# Japanese Tutor

A chapter-indexed Japanese grammar revision site based on the supplied Try! N3 Grammar Points notes.

The static site is in `docs/`. Structured grammar data is kept separately at `docs/data/grammar.json`; each card links back to its original chapter and point number.

To publish with GitHub Pages, choose the `main` branch and `/docs` folder under repository Settings → Pages. The published site is public by URL.
